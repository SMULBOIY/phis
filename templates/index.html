How the detection pipeline works

The same 15-feature extractor is used offline for training and at request time.

01

One bounded URL string

Input is validated, normalised and capped in length. No DNS lookup, socket or HTTP client is involved.

02

Fifteen lexical characteristics

Length, dots, hyphens, digits, subdomains, HTTPS, IP literal, suspicious words, encoding and more.

03

A measured model score

A persisted estimator emits an uncalibrated score. It is an estimate, not a guarantee that a site is malicious.

04

Three honest decision states

Two calibrated cut-offs create an abstention band for unresolved cases, with warnings and a recommended action.

SAFETY NOTICE

No submitted URL is visited, resolved or executed, so there is no SSRF surface and no contact with live malicious sites. A LEGITIMATE result is not a guarantee that a website is safe. Results are correlations learned from a specific training distribution, not universal truths about the web.
